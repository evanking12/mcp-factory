# Legacy Provider Live Green Campaign

## Governing Objective

Make every sponsor non-VM format prove a GPT tool call with a real tool result.
Provider-required remains a fallback only when the hosted legacy provider layer is
disabled or unreachable; it is not an acceptable required green result.

## Evidence Scope

The campaign may act only on repository files, CI artifacts, deployed pipeline/UI
health routes, and explicit user-provided paths. It must write tranche evidence
under this directory before advancing gates.

## Required Gates

1. Workflow speed controls and report-only iteration path exist.
2. Pipeline API hosts deterministic legacy providers for REST/OpenAPI,
   JSON-RPC, SOAP, SQL, CORBA, RPC IDL, and JNDI.
3. Executor routes generated tools to hosted providers by default.
4. GPT matrix requires `tool_call`, `tool_result`, and sentinel/result observed
   for all 13 non-VM sponsor cases.
5. Sponsor report HTML and UI proof-bundle affordance are available.
6. Final Sponsor Demo E2E is green with `13/13` live execution proofs and
   `0` required provider-required cases.

## Stop Rules

Do not call the campaign complete until local tests pass, the workflow surfaces
diagnostic artifacts, and the campaign closeout records a canonical green run.
