## Artifact Map

Inside the `sponsor-demo-e2e` GitHub Actions artifact:

- `final-summary.md`: sponsor-readable pass/fail report.
- `final-summary.json`: machine-readable gate and requirement matrix.
- `sponsor-report.html`: browsable static report.
- `ci_artifacts/demo/gpt-format-matrix/summary.json`: GPT-4o format proof matrix.
  The runtime expansion version includes `runtime_mode_counts`,
  `runtime_backed_cases`, `adapter_backed_cases`, and per-case transcript paths.
- `ci_artifacts/demo/windows/summary.json`: Windows bridge discovery summary.
- `ci_artifacts/demo/windows-gpt/summary.json`: Windows GPT tool-call proof matrix when generated by this hardening campaign.
- `ci_artifacts/demo/repo-ingestion/summary.json`: repo ingestion GPT proof when generated by this hardening campaign.
- `docs/sponsor/caveats.md`: proof boundary and caveats.

These are GitHub Actions proof artifacts. App-user downloads remain backend blob
downloads served through `/api/download/{job_id}/{filename}`.

## Interpretation

Use `sponsor-report.html` for live review and `final-summary.json` for exact
automation status. The caveat page should be shown when discussing CORBA, RPC,
JNDI, DCOM, or arbitrary closed-source binary recovery. JSON-RPC, SOAP, SQL,
JNDI/LDAP, CORBA ORB/IIOP, and controlled MSRPC are runtime-backed in the
expanded proof. Focused run `24577926238` proves controlled same-subnet Remote
DCOM through WMI over DCOM; it becomes part of the canonical claim only after a
full Sponsor Demo E2E imports that artifact and passes.
