Run it yourself

Live runs stay local

The public site is static for safety. To execute real analysis, clone the repo, provide your own model provider key, install the local bridge/Ghidra dependencies, and start the managed local stack. 

git clone <repo-url>
cd mcp-factory
copy .env.example .env
# add your own model provider key in .env
powershell -ExecutionPolicy Bypass -File .\start.ps1 -NoBrowser
open http://127.0.0.1:8082/simple
